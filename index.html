Es is normalized to 1 for every constellation. With k bits per symbol, Es/N0 = k·Eb/N0, so N0 = 1/(k·Eb/N0). Complex noise has variance N0, split as σ² = N0/2 on each of I and Q. BFSK uses two orthogonal unit-energy signals (k = 1, Es = Eb) with the same σ per dimension.
